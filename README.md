# Midnight World

A dark-themed, responsive social voice-room website prototype.

## Run locally
Open `index.html` in a modern web browser.

## Deploy
Upload `index.html` to the root of a GitHub repository, then import the repository into Vercel.

## Prototype limitations
Rooms, chat, profiles, gifts, and coins are demo interactions stored only in the current page session. There is no real authentication, persistent database, or live voice transmission yet.
